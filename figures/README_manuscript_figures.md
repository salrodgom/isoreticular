# manuscript_figures

Reproducible figure pipeline for the manuscript

  *Isoreticular order as a tuning knob for framework softness in the RHO zeolite family*
  Balestra & Ruiz-Salvador

Each figure of the paper is generated by a single self-contained gnuplot
script in `scripts/`. Scripts read tabular inputs from `data/` and write
EPS/PDF outputs to `build/`. Python helpers in `scripts/` (only when
unavoidable) prepare the `.dat` files that gnuplot consumes; they do
**not** plot anything.

## Layout

    manuscript_figures/
        scripts/        gnuplot (.gp) and prep helpers (prep_*.py)
        data/           tabular inputs (.dat, .csv) consumed by .gp scripts
        build/          generated EPS outputs                          -- gitignored
        Makefile        `make all` rebuilds every figure; `make clean` wipes build/
        sync_to_overleaf.sh   copy `build/*.eps` into the Overleaf `images/` folder
        README.md       this file

## Reproducing a single figure

    make fig5e
    make figS2

(figure target names match the section labels of the paper)

## Reproducing all figures

    make all

This calls every `scripts/fig*.gp` in order and writes `build/<name>.pdf`.

## Pushing to the Overleaf project

    ./sync_to_overleaf.sh

This copies `build/*.pdf` into

    /home/salvador/Dropbox/Aplicaciones/Overleaf/Structural changes in the RHO family of embedded isoreticular zeolites/images/

(i.e., the Overleaf-linked Dropbox folder). The Overleaf compile picks up
the new PDFs automatically.

## Dependencies

  gnuplot >= 5.2 (with the `postscript` terminal)
  Python >= 3.8 with `numpy` and `pandas` (only for the prep helpers)

The Overleaf project loads `\usepackage{epstopdf}` so pdflatex ingests
`.eps` natively; no separate EPS->PDF conversion step is needed here.

## Style conventions

  - **Terminal**: ONLY
        set term postscript eps color enhanced blacktext 'Helvetica,XX'
    where `XX` follows the table below. No `pdfcairo`, `pngcairo` etc.
  - Each `.gp` produces an EPS and only an EPS. The LaTeX build of the
    manuscript handles the EPS->PDF conversion via the `epstopdf`
    package.
  - No in-plot titles (panel letters go in the LaTeX subcaption).
  - LaTeX-compatible labels (`{/Helvetica-Italic ...}`, `{/Symbol D}` for
    Δ, etc.), British English spelling, no en-dashes, no em-dashes.
  - Colour palette follows Figure 5 of the manuscript:
        G_1 red    (#cb4335)
        G_2 yellow (#f1c40f)
        G_3 green  (#27ae60)
        G_4 blue   (#2874a6)
        G_5 purple (#7d3c98)

### Font size XX vs LaTeX inclusion width

  | LaTeX inclusion in main.tex                     | XX |
  |-------------------------------------------------|----|
  | `width=\textwidth` (full-width single panel)    | 26 |
  | `width=\textwidth` of a 0.49\textwidth subfig   | 22 |
  | `width=\textwidth` of a 0.32\textwidth subfig   | 20 |
  | Small inset                                     | 18 |

  This keeps the printed-page label cap-height at ~9-11 pt across all
  figures, regardless of inclusion size, matching the existing
  `gp_isoOvsPc` and `gp_Figure3` of the project.
